Маркировка определяется только по совпадению пары кодов ТН ВЭД + ОКПД2 в перечне. Результат носит рекомендательный характер: окончательное решение — по НПА, ссылка на который есть в карточке. Для медизделий дополнительно проверяются РУ и код вида НКМИ, для БАД и детского питания — СГР. Эксперимент не создаёт обязанности маркировать товар и не отменяет обязанность, установленную перечнем обязательной маркировки.
